# 🦁 Sprinter Tours & Safaris

Sprinter Tours & Safaris is a full-stack tourism and safari booking website designed to allow customers to explore destinations, view safari packages, create accounts, make bookings, and access online payment options.

The project was developed using HTML, CSS, JavaScript, PHP, and MySQL.

---

## ✨ Features

- Responsive tourism and safari website
- Safari destination pages
- Tour and travel packages
- Image gallery
- Customer registration and login
- Online safari booking system
- Customer booking history
- Booking management
- Contact and messaging functionality
- Administrative dashboard
- Booking editing and deletion
- PDF export functionality
- Excel export functionality
- Payment processing integration
- M-Pesa STK Push integration
- Paystack card payment integration
- Payment verification
- Receipt generation and verification

---

## 💳 Payment Integrations

The project includes support for:

### M-Pesa

M-Pesa payments are integrated using the Safaricom Daraja API and STK Push.

### Paystack

Paystack is used for card-payment processing and payment verification.

### PayPal

PayPal integration is included in the project structure but is currently under development.
